# ARTIFACTS_INDEX.md

## Назначение документа

ARTIFACTS_INDEX.md описывает **полный набор артефактов**, используемых
в мультиагентском пайплайне разработки.

Документ определяет:

- какие артефакты существуют
- кем они создаются
- кем они потребляются
- являются ли они генерируемыми или статическими
- на каком этапе пайплайна они появляются

ARTIFACTS_INDEX.md является **системным контрактом** и не генерируется агентами.

---

## Классификация артефактов

Все артефакты делятся на три категории:

1. **System Contracts** — статические, глобальные
2. **Pipeline Artifacts** — генерируемые в рамках проекта
3. **Execution Artifacts** — пофичевые, итерационные

---

## 1. System Contracts (Static)

Эти файлы:

- существуют ДО запуска пайплайна
- не изменяются агентами
- лежат рядом с агентами
- описывают КАК работает система

| Artifact                 | Description                    | Used by               |
|--------------------------|--------------------------------|-----------------------|
| AGENTS_INDEX.md          | Реестр агентов и ролей         | Pipeline Orchestrator |
| ARTIFACTS_INDEX.md       | Реестр артефактов              | All                   |
| QUALITY_SCORING.md       | Правила оценки качества (0–10) | Verifiers             |
| pipeline-orchestrator.md | Спецификация оркестратора      | System                |
| agent specs (*.md)       | Спецификации агентов           | System                |
| AGENT_PROFILE_*.md       | Доменные профили агентов       | Execution agents      |

**Расположение (рекомендуемое):**

```text
~/.claude/agents/
````

## Правила владения артефактами (MANDATORY)

* Каждый артефакт имеет **ровно одного автора-агента**
* Другие агенты могут:

    * читать
    * ссылаться
    * проверять
* Ни один агент не имеет права:

    * изменять чужой артефакт
    * дописывать его вручную

---

## Правила версионирования

* Все pipeline и execution артефакты:

    * версионируются
    * не перезаписываются
* Новая версия = новый файл или версия в заголовке

## Каноническое правило (зафиксировать)

> **Если файл описывает КАК работает система —
> он статический и глобальный.
> Если файл описывает ЧТО делается в проекте —
> он генерируемый и проектный.**
